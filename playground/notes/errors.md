# 错误码

QHP 的错误码格式是 `QHE-xyz`，百位数表示出错的步骤：1 探活、2 握手、3 票证交换、4 会话锁定，9 表示通用错误。

| 错误码 | 含义 | 处理 |
|--------|------|------|
| QHE-101 | 连续 3 个 PING 都没有 PONG | 放弃本轮建立 |
| QHE-203 | 能力字 `qhx` 交集为空 | 直接结束，不进入票证交换 |
| QHE-305 | 票证版本过低（出示了 V1） | 拒绝，要求换成当前票证格式 |
| QHE-412 | 双方写入的 `session-epoch` 不一致 | 拆除连接，从探活重新开始 |
| QHE-900 | 等待应答超时，并且重试次数已用完 | 上报，不再自动重试 |

具体的通过条件看各步骤对应的笔记，本页只列错误码。
