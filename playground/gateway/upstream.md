# 上游回连和摘除

## 回连

网关和某个上游之间的链路断开后，网关会主动回连这个上游：

- 间隔依次是 1、2、4、8、16 秒
- 最多回连 **5** 次
- 任何一次成功就停止，恢复转发

## 摘除

5 次回连都失败时：

1. 记一条 `QHE-507`
2. 把这个上游**摘除**：移出转发列表，新会话不再分给它，改分给其他上游
3. 摘除后冷却 **600 秒**，冷却结束自动加回转发列表，再试一轮

想提前加回，执行 `qhpctl gw readd <上游地址>`。

## 所有上游都被摘除

没有任何可用上游时，新会话返回 `QHE-501`。

## 和 SDK 的自动重连不是一回事

这里说的是网关和上游之间的回连。客户端 SDK 和网关之间断开后怎么办，看 `sdk/` 下各语言的文档。
