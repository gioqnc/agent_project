# QHP 网关概览

QHP 网关（进程名 `qhp-gw`）部署在实验室内网入口，把客户端的会话转发给上游的 qhpd 节点。客户端只需要知道网关地址，不用关心上游有几台。

## 端口

- 客户端连网关：**4722**
- 管理接口：`127.0.0.1:9090`，HTTP，只监听本机，提供 `/healthz`（健康检查）和 `/metrics`（监控指标）

注意网关端口和 qhpd 的 4721 不是同一个，直连 qhpd 才用 4721。

## 网关做什么、不做什么

- 做：把会话分配给某个上游、维护和上游之间的泊位、上游断开后回连、把连不上的上游摘除
- 不做：不校验票证。票证原样透传，由上游 qhpd 校验
