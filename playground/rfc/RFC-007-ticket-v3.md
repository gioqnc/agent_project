# RFC-007：票证格式 V3

**状态：已否决**（2026-05-20 协议组周会）

## 动机

希望票证能限定可以使用的帧类型，并且防止同一张票证被重复出示。

## 提议的 QH-TICKET-V3 格式

票证用 CBOR 编码，包含以下字段：

| 字段 | 说明 |
|------|------|
| `ver` | 固定为 3 |
| `issuer` | 签发方 |
| `scope` | 允许使用的帧类型，比如 `["txt", "hb", "ack"]` |
| `nonce` | 随机数，对端记录用过的 nonce，防止重复出示 |

## 兼容性

V3 和 V2 不兼容。启用 V3 需要所有 qhpd、网关和客户端同时升级。

见 `meetings/2026-05-20.md`。
